# The World in One Day — Friday 13 November 2026

A newspaper front page summing up 13 November 2026 world news in one
1024x1024 image.

**Stories:** NVIDIA CEO Jensen Huang resigns (lead); Iran claims a radar
strike in Bahrain; Europe joins the Ukraine peace talks; the Microsoft
outage enters day 2; a U.S. FAA failure grounds flights nationwide;
China's Pacific naval drills; plus a strip with the Pope in Lima, the
$1.2bn Binance-hack crypto seizure, and the Brooklyn collapse toll.

**How it was made:** drawn entirely in code with Python + PIL
(`build_image.py`, DejaVu fonts) — no image-generation model, so every
word is spelled correctly and stays legible. The grader entrypoint
(`main.py`, stdlib only) just copies the pre-rendered `entry.png` to
`MAKEFUN_OUTPUT_DIR`.
